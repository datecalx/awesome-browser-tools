# Contributing

Thanks for contributing to Awesome Browser Tools!

We welcome useful, free online tools that provide real value to users.

## How to Add a Tool

1. Fork this repository.
2. Add your tool to the most relevant category in `README.md`.
3. Keep the entry in alphabetical order.
4. Submit **one tool per pull request**.
5. Open a pull request with a short explanation.

Use this format:

```markdown
- [Tool Name](https://example.com/) - Short, accurate description of what the tool does.
